# 个税计算器小程序 SEO 优化设计

**日期**：2026-08-06  
**状态**：已通过并实现  
**方案**：B（标题 + 可索引内容 + 后台配置清单）  
**主关键词**：个税计算器（辅：个人所得税计算器）

## 1. 目标与边界

### 目标

提升微信小程序搜索中对「个税计算器」「个人所得税计算器」的可发现性。

### 范围内

- 代码：全局/页面标题、首页说明文案、帮助页 FAQ、分享标题
- 文档：公众平台后台名称/简介/标签操作清单（不改后台，仅提供文案）

### 范围外

- 不改计税逻辑、不改页面路由 path
- 不堆砌关键词、不出现「官方 / 税务局 / 精准报税」等审核红线词
- 不依赖流量主或付费推广

沉浸式页头文案同步植入主词（不改变布局结构）：

- 首页 `immersive-header`：title 改为「个税计算器」，subtitle 保留税率说明并含「个人所得税」
- 汇算页：title 可改为「个税计算器·年度汇算」或保持功能名 + subtitle 含主词

### 2.2 首页可索引说明

在首页主操作区上方或模式切换下方，增加 **一行** 产品说明（纯文本，可被爬虫索引），例如：

> 个税计算器：按现行个人所得税政策，测算工资薪金、年终奖、劳务报酬与年度汇算，结果仅供参考。

样式轻量，不挡表单；不使用卡片堆叠营销模块。

### 2.3 帮助页 FAQ

在税率表之前或之后增加 FAQ 区块（4–6 条），正文自然出现主词，并保留免责声明。建议条目：

1. 什么是个税计算器？如何测算个人所得税？
2. 工资个税怎么算？（累计预扣预缴简述）
3. 年终奖个税单独计税与合并计税有何区别？
4. 年度汇算清缴是什么？什么时候办理？
5. 专项附加扣除包括哪些？
6. 测算结果是否等于实际纳税？（指向官方系统免责）

文案语气：工具说明，不用「官方」「精准报税」。

### 2.4 分享

在以下页面的 Page 中增加 `onShareAppMessage`（及可选 `onShareTimeline`，若基础库已支持且项目需要）：

- `pages/index/index`
- `pages/bonus/bonus`
- `pages/annual/annual`
- `pages/labor/labor`
- `pages/help/help`

分享标题统一含主词，例如：`个税计算器 - 工资薪金个税测算`；path 指向当前页。

可在对应页面 `json` 中开启 `enableShareAppMessage`（自定义导航页如需分享菜单时按微信文档配置）。

### 2.5 sitemap

保持现有全站 `allow`，无需变更。历史详情页若不想被索引，可后续单独 `disallow`；本期不做。

## 3. 后台配置清单（人工）

发布代码后，在微信公众平台按下列文案调整（需管理员权限）：

| 项 | 建议 |
|----|------|
| 小程序名称 | 优先「个税计算器」；若重名不可用，用「个税计算器Pro」等短变体，仍以「个税计算器」开头 |
| 简介 | 前两句必须含「个税计算器」「个人所得税」及能力点：工资/年终奖/汇算/劳务报酬；注明「测算仅供参考」 |
| 标签/搜索相关 | 个税计算器、个人所得税计算器、工资个税、年终奖计税、年度汇算 |
| 服务类目 | 工具类合适类目（以平台当前可选为准） |
| 红线 | 禁止：官方、税务局、精准报税 |

简介示例（可直接粘贴微调）：

> 个税计算器，免费个人所得税测算工具。支持工资薪金、年终奖、劳务报酬与年度汇算清缴测算，内置税率表与专项附加扣除说明。测算结果仅供参考，最终以国家税务总局官方系统为准。
